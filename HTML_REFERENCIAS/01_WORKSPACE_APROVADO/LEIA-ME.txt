SONDER CLINIC — PROTÓTIPOS PARA APROVAÇÃO VISUAL

1. Extraia o arquivo ZIP.
2. Abra index.html no navegador.
3. Use a barra lateral para navegar por todos os módulos.
4. Clique em agendamentos, tarefas, laboratórios, menus e abas para testar interações.
5. Após a aprovação visual, será produzido um único Markdown técnico para implementação integral no Cursor.

Os protótipos usam dados fictícios somente para demonstração visual.
